# BirdNET phone field test

The files at `apps/web/public/weather/field-listen/` are an adapted build of BirdNET-Team's real-time web app. They let a phone identify bird sounds locally in its browser, separately from the stationary camera feed. The public weather card shows only the station bird report. Approved Monosyth admins see a link to `/weather/listen`, which signs them in and opens the protected listening page.

To rebuild, clone the pinned revision in a temporary directory, apply `monosyth.patch`, run `npm ci` and `npm run build`. Copy `_site/index.html` to `apps/web/src/private/weather/field-listen/index.html`; never put it under `public`. Replace the other required static assets in `apps/web/public/weather/field-listen/`, including `legal/index.html`. The route `/weather/field-listen/index.html` serves the private HTML only after verifying a short-lived, HTTP-only Firebase admin session cookie. The customized build uses `/weather/field-listen/` as its base path and turns location off by default. Do not add the upstream institutional privacy notice back to the hosted page.

This is a field test. Each new BirdNET identification shown as a live card is saved immediately with its time in a journal in the phone's browser. One shared "Show and save birds above" threshold controls both the visible cards and automatic saving, including existing phone settings below the 15% default. Repeated appearances of the same species within 90 seconds are grouped in one entry, with a listening-check count increased at most once every three seconds and five visual ticks. The peak BirdNET model score stays separate from this count. Users can save a live suggestion manually, adjust the threshold, export the journal as CSV, or clear it. A separate setting saves approximately six seconds of processed audio with each new journal entry in IndexedDB; this is off by default, and clips can be played or downloaded individually. Names and clips stay on the phone and are not added to the weather station's BirdNET history. The model download is about 64 MB, so a first visit is best on Wi-Fi. Microphone access requires HTTPS and a user tap on Start.

The quiet-yard starting button sets show/save to 10%, automatic saving on, BirdNET sensitivity to 1.0, microphone gain to 1.0x, low-rumble filter to 200 Hz, and sound checks to 500 ms. It does not change geolocation or the optional audio-clip choice. Spectrogram controls affect only the display.
